# Data availability and privacy

Patient-level development and validation datasets are not included in the public repository or Zenodo archive because of privacy, informed-consent, and institutional-governance restrictions.

The public GitHub repository provides the analysis and implementation code supporting the reported workflow, including the Shiny source, prediction code, publication-lock feature-selection code, variable dictionary, model specification, synthetic example input/output, software/session information, and reproducibility/concordance scripts:

https://github.com/lienguang95-hue/OSA-MCI-RF-model

The locked RF model object and the versioned reproducibility package are permanently archived in Zenodo:

**DOI: 10.5281/zenodo.21872475**

https://doi.org/10.5281/zenodo.21872475

De-identified participant data may be considered by the corresponding authors and participating institutions upon reasonable request and applicable approval, consistent with the manuscript's data-availability statement.

No real patient records should be committed to this repository or embedded in the public web application.
