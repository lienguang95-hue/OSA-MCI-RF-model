# Locked RF model object

The deployed Shiny calculator uses the locked nine-predictor random-forest object `AAA_locked_RF_bundle.rds`.

Publication-lock properties:

- model: random forest;
- final predictors: 9;
- positive class: `Yes`;
- training-derived prioritization threshold: `0.3228`;
- SHA-256 of the canonical locked RDS file: `7aac8100312e67b8929c353465e41702c14bcf1ae9d54bc5418540a6eaf6b463`.

The connected GitHub writing interface used to assemble this repository does not support direct transfer of the local binary RDS object. Therefore, the binary itself is **not yet present in this GitHub tree**. The public source code, variable dictionary, synthetic examples, software environment, and live executable Shiny implementation are available here. The identical locked RDS binary should be added to the permanent Zenodo/software archive before the revision is formally submitted, and this README should then be replaced by the binary file or linked to that archived DOI.

Do not represent the binary model object as publicly downloadable from this GitHub repository until that archival step has been completed.
