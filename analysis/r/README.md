# R analysis-code scope

The R files in this folder are supporting analysis scripts retained for transparency. The authoritative publication-lock feature-selection implementation is the synchronized Python code in `../python/`.

Patient-level source data are restricted and are not distributed publicly. Therefore these scripts are provided for methods inspection and for authorized reruns with appropriately governed data; they are not claimed to be externally runnable from the public archive alone.

The obsolete online-calculator script and historical exploratory feature-selection scripts are intentionally excluded from the public package because the deployed calculator uses the locked RF bundle and the revised manuscript uses the publication-lock synchronized feature-selection description.
